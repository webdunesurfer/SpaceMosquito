# FAQ

Explanations that outlive individual tasks: domain concepts, formulas, CLI/API how-tos, conventions.

## When to add a page

- A concept is referenced often and should not be re-explained in every task doc.
- Behavior or semantics need a single source of truth for humans and agents.
- On release, lasting detail from a deleted task doc belongs here (or in an ADR / layer README).

## Conventions

- One topic per file: `docs/faq/<topic>.md` (snake_case or kebab-case; be consistent in the repo).
- Link from [`dev/README.md`](../../dev/README.md) once the page is real.
- Copy [`TEMPLATE.md`](TEMPLATE.md) for a new page.
